# Grow Day Privacy Policy Draft

Last updated: TODO

This document is a draft for Play Store review and should be checked before publication.

## App Name

Grow Day

## Personal Information Collection

Grow Day does not collect personal information.

The app does not require account sign-up, login, email address, phone number, or user profile information.

## Data Created by the User

Users may write work logs, goal records, tags, mood status, notes, and related text inside the app.

This data is stored locally on the user's device using SQLite.

## Server Transfer

Grow Day does not send user-created records to an external server.

Grow Day currently does not operate a server database for user records.

## Backup and Sync

Grow Day currently does not provide separate backup or sync features.

If the app is deleted, local data stored on the device may also be deleted depending on the device and operating system behavior.

## Third-Party Sharing

Grow Day does not share user-created records with third parties.

## Permissions

Grow Day does not request unnecessary device permissions for its core logging features.

## Children's Privacy

Grow Day is not designed to knowingly collect personal information from children.

## Changes to This Policy

This privacy policy may be updated if app features or data handling practices change.
