# Tiny Growth — 성장 모험 로그 디자인 검토

작성일: 2026-06-20  
대상: `expo-lab` 저장소 `dev` 브랜치  
범위: 디자인 분석 및 적용 계획만 포함하며 코드, 기능, 내비게이션, DB는 변경하지 않는다.

## 검토 전제

- 목표는 Tiny Growth를 지금보다 귀엽고 따뜻한 **성장 모험 로그**로 다듬는 것이다.
- 참고 이미지에서는 자연 배경, 둥근 형태, 편안한 색, 모험 일지의 서사를 참고한다.
- 참고 이미지의 화면 구성, 캐릭터, 아이콘, 보상 체계, 문구를 복제하지 않는다.
- 특히 동물 아바타 중심의 자기관리 앱처럼 보이지 않도록 Tiny Growth의 기존 **씨앗과 새싹** 언어를 고유한 시각 정체성으로 사용한다.
- Today / Archive / Report / Search / Settings 탭과 Write / Detail / GoalManage 화면 구조는 그대로 유지한다.
- 기존 로그, 목표, 통계 데이터만 표현하며 새로운 진행도, 재화, 레벨, 장소, 보상 데이터는 만들지 않는다.
- 지정된 최종 참고 이미지 경로는 다음과 같다.
  - `docs/design-reference/cozy-adventure-01.png`
  - `docs/design-reference/cozy-adventure-02.png`
  - `docs/design-reference/cozy-adventure-03.png`

현재 지정 경로에는 이미지가 아직 없으므로, `docs`에 임시로 놓인 3개의 참고 이미지를 검토했다. 최종 파일이 지정 경로에 추가되면 구현 전에 색상, 여백, 밀도만 다시 대조해야 한다.

## 1. 현재 Tiny Growth와 레퍼런스 디자인의 차이

| 구분 | 현재 Tiny Growth | 레퍼런스에서 보이는 방향 | 해석 |
| --- | --- | --- | --- |
| 제품 인상 | Linear·Raycast 계열의 차분한 생산성 도구 | 캐릭터가 이끄는 밝은 자연 속 모험 | 기능적 신뢰감은 현재가 강하고, 매일 열고 싶은 정서적 동기는 레퍼런스가 강하다. |
| 배경 | 단색에 가까운 짙은 정원색 또는 옅은 녹백색 | 하늘, 언덕, 나무가 층을 이루는 녹색 풍경 | 전체 일러스트를 복제하지 말고 추상적인 정원 레이어로 깊이만 추가하는 편이 안전하다. |
| 카드 | 낮은 대비의 어두운 표면, 26px 라운드 | 밝고 큰 흰색 카드, 매우 둥근 모서리 | 현재 반경은 이미 충분하다. 색, 내부 구획, 여백을 부드럽게 조정하는 것이 우선이다. |
| 상징 | 작은 코드 드로잉 `TinySprout` | 화면 중심의 동물 캐릭터와 소품 | 새 캐릭터보다 새싹을 표정 없는 작은 길잡이·성장 표식으로 확장해야 고유성이 유지된다. |
| 목표 표현 | 체크리스트와 완료율 중심 | 에너지와 보상이 붙은 퀘스트 목록 | 목표의 읽는 순서와 카드 형태만 퀘스트처럼 만들고 보상·재화는 도입하지 않는다. |
| 리포트 표현 | 통계 카드, 막대 차트, 태그·기분 집계 | 월간 여행지와 완료 배지 중심의 모험 일지 | 실제 통계는 유지하고 제목, 구획, 시각적 연결선을 일지 문법으로 바꿀 수 있다. |
| 색상 | 딥 그린, 민트, 세이지, 씨앗색 | 라임 그린, 하늘색, 노랑, 흰색 중심 | 현재 팔레트를 밝고 따뜻하게 확장하되 채도와 색 수를 제한해야 한다. |
| 타이포그래피 | 단정하고 촘촘한 생산성 계층 | 크고 굵고 친근한 제목 | 제목의 둥근 인상과 행간만 강화하고 본문 가독성과 데이터 밀도는 유지한다. |
| 감정 톤 | 조용한 성장과 기록 | 즉각적인 즐거움과 보상 | Tiny Growth에는 “조용한 작은 모험”이 적합하다. 흥분보다 발견과 축적에 초점을 둔다. |

현재 디자인은 이미 민트·세이지·씨앗색, 둥근 카드, 새싹 모티프를 갖고 있어 방향 전환보다 **정서와 표현 계층을 한 단계 따뜻하게 조정하는 작업**에 가깝다.

## 2. Tiny Growth에 적용하면 좋은 디자인 요소

### 자연 배경의 추상화

- 단색 배경 위에 저대비의 원형 언덕, 잎, 햇살 같은 큰 면을 2~3개만 배치한다.
- 실제 숲이나 여행지 일러스트 대신 “새벽 정원”, “햇살 정원”처럼 색면으로만 자연을 암시한다.
- 콘텐츠 영역의 대비와 스크롤 성능을 해치지 않도록 화면 상단 hero 안에서 주로 사용한다.
- 다크 모드는 밤의 정원, 라이트 모드는 아침의 정원이라는 한 쌍의 표현으로 맞춘다.

### 새싹을 Tiny Growth의 고유한 안내자로 사용

- `TinySprout`의 씨앗·줄기·잎 형태는 유지한다.
- 크기와 성장 단계의 변형만 허용한다. 얼굴, 의상, 펫 육성, 사용자 아바타 설정은 추가하지 않는다.
- Today hero, 빈 상태, 저장 완료, Report 시작점처럼 의미 있는 지점에만 제한적으로 둔다.
- 작은 점선 경로, 잎 표식, 씨앗 마커와 조합해 기록의 흐름을 보여준다.

### 둥근 카드와 부드러운 레이어

- 카드 반경 26px은 유지하고, hero 또는 월간 요약 카드만 28~32px 범위로 강조한다.
- 카드 안에 얇은 경계선 대신 연한 내부 면과 작은 색상 배지를 사용한다.
- 그림자는 라이트 모드에서만 매우 약하게 사용하고, 다크 모드는 표면 명도 차로 구분한다.
- 카드 간격을 충분히 유지해 장난감 UI가 아닌 편안한 노트처럼 보이게 한다.

### “기록 = 작은 모험” 서사

- 모험을 경쟁이나 보상이 아니라 **오늘 발견한 것, 해결한 것, 남긴 흔적**으로 정의한다.
- “퀘스트”를 전면 용어로 쓰기보다 “오늘의 작은 여정”, “오늘의 발걸음”, “모험 메모” 같은 Tiny Growth다운 표현을 우선한다.
- 완료 상태는 점수 대신 잎이 채워지거나 씨앗 마커가 다음 지점으로 이동한 듯한 정적인 표현을 사용한다.
- 기존 로그, 목표 완료율, 연속 기록 수만 활용하고 새로운 게임 상태를 만들지 않는다.

### 파스텔 보조 팔레트

- 기존 민트와 세이지를 중심색으로 유지한다.
- 씨앗 노랑은 발견·강조에만 사용한다.
- 하늘색과 복숭아색은 각각 정보와 기분 표현에 제한적으로 추가할 수 있다.
- 한 화면에서 강조색은 주색 1개와 보조색 1개까지만 사용한다.

권장 탐색 범위이며 구현 전에 명암비를 검증해야 한다.

## 3. 적용하면 위험한 요소

### Finch와 직접 연결되는 제품 문법

- 화면 중앙의 큰 동물 캐릭터
- 캐릭터 의상, 집, 동료, 여행지 수집
- 번개·에너지, 사탕·코인, 보상 상자, 연속 출석 보상
- 모험 복귀 타이머와 장소 해금
- 목표마다 보상 수치를 붙이는 방식
- 참고 이미지와 유사한 하단 아이콘 구성, 흰색 외곽선 아이콘, 배지 모양

이 요소들은 단순한 디자인이 아니라 다른 제품의 핵심 정체성이다. 적용하면 Finch의 축소판처럼 보이고, 새 기능 금지 및 기존 DB 유지 조건도 위반할 가능성이 높다.

### 과도한 게임화

- 모든 목표를 “퀘스트”, 모든 로그를 “승리”로 바꾸면 업무 기록의 진지함이 약해진다.
- 레벨, 경험치, 지도, 스테이지를 암시하면 사용자가 실제 진행 기능을 기대하게 된다.
- 목표 미완료를 실패나 패배로 표현하면 부담 없이 기록한다는 목표와 충돌한다.
- 완료 애니메이션과 장식이 반복되면 빠른 기록 흐름을 방해한다.

따라서 모험은 **정보 구조가 아니라 편집 톤과 시각적 은유**로 제한한다.

### 배경과 색상의 과밀화

- 전체 화면 숲 일러스트는 카드 가독성을 낮추고 다크 모드의 장점을 없앤다.
- 밝은 초록을 넓게 사용하면 눈의 피로와 낮은 텍스트 대비가 발생할 수 있다.
- 여러 파스텔을 같은 비중으로 사용하면 어린이용 앱처럼 보일 수 있다.
- 큰 이미지 에셋은 앱 용량, 다양한 화면 비율, 테마 대응 비용을 증가시킨다.

### 기존 디자인 시스템과의 충돌

- 기존 문서의 “게임 용어를 재도입하지 않는다”는 원칙과 이번 모험 콘셉트 사이에 긴장이 있다.
- 해결 기준은 “게임 규칙은 추가하지 않고, 하루 기록을 작은 여정으로 서술한다”이다.
- 기존 개발자 생산성 앱의 정보 계층과 빠른 입력 흐름은 반드시 유지해야 한다.

## 4. 화면별 개선 방향

### Home / Today

현재 구조인 hero → 주간 성장·완료율 → 오늘 목표 → 기록 CTA 순서를 유지한다.

- hero를 “오늘의 작은 여정”을 여는 정원 카드로 재구성한다.
- 상단 배경에 저대비 언덕 2개와 작은 새싹을 코드 드로잉으로 배치한다.
- 연속 기록 수와 7일 막대 차트는 유지하되, 차트 바를 “자라난 잎”처럼 둥글고 부드럽게 표현한다.
- 주간 성장과 오늘 완료율 카드는 동일한 높이와 옅은 파스텔 틴트로 구분한다.
- 목표 영역은 한 장의 큰 카드 안에서 선으로 나누기보다 각 목표를 작은 둥근 행 카드로 분리한다.
- 반복 목표와 오늘만의 목표는 작은 배지로 구분하며, 보상·난이도·에너지 표시는 추가하지 않는다.
- 완료 체크는 기존 동작을 유지하고, 완료 시 체크 영역의 민트 면과 작은 잎 점만 변화시킨다.
- 하단 CTA는 “오늘의 성장 기록하기”처럼 기록 행동이 명확한 문구를 유지한다. “모험 시작”처럼 새 기능을 기대하게 하는 표현은 피한다.

### Report

현재 통계 요약 → 인사이트 → 태그 → 최근 6개월 → 기분 통계 구조를 유지한다.

- 헤더를 “이번 달의 성장 모험 로그”로 해석하되 월과 기록 수를 가장 크게 보여준다.
- 월간 기록 수, 주간 기록 수, 연속 기록, 평균 완료율은 기존 데이터 그대로 “이번 달에 남긴 흔적” 카드에 담는다.
- 인사이트 목록은 점선 길과 씨앗·잎 마커를 사용한 세로형 일지로 표현한다.
- 최근 6개월 막대 차트는 유지하고 각 월을 작은 정원 구획처럼 둥근 막대로 보여준다.
- 태그는 “자주 발견한 주제”, 기분은 “여정의 날씨” 정도의 보조 카피로 재해석할 수 있다. 실제 필드와 계산은 바꾸지 않는다.
- 빈 상태는 지도나 잠금 장소 대신 빈 화분과 첫 씨앗으로 표현한다.
- 여행지, 달성 배지, 100% 스탬프는 실제 데이터 의미와 맞지 않으므로 사용하지 않는다.

### Goal / GoalManage

현재 새 반복 목표 입력 → 카테고리 선택 → 목표 목록과 활성화 토글 구조를 유지한다.

- 제목은 “반복 목표 관리”를 유지하거나 “반복하는 작은 발걸음”을 보조 문구로 추가한다.
- 카테고리 칩은 건강·공부·일·생활·성장·기타의 기존 값을 그대로 쓰고, 각 칩에 제한된 파스텔 틴트를 적용한다.
- 목표 행을 Today의 목표 카드와 같은 계열로 통일한다.
- `ON/OFF`는 동작을 유지하되 활성 상태를 새싹색, 비활성 상태를 휴식 중인 씨앗색으로 시각화한다.
- 활성화를 “퀘스트 수락”, 비활성화를 “포기”로 표현하지 않는다. 사용자의 부담을 키우기 때문이다.
- 새 목표 추가 패널에 작은 씨앗 아이콘을 둘 수 있으나 별도 캐릭터나 보상 설명은 넣지 않는다.

### Settings

설정은 장식보다 명확성이 중요한 화면이므로 콘셉트를 가장 약하게 적용한다.

- 현재 언어와 현재 테마 카드를 하나의 “나의 정원 환경” 요약 영역처럼 시각적으로 묶을 수 있다.
- 다크 모드는 “밤의 정원”, 라이트 모드는 “아침의 정원”이라는 보조 설명을 사용할 수 있지만 저장 값은 `dark` / `light` 그대로 유지한다.
- 언어와 테마 선택 행의 둥근 형태, 선택 체크, 접근성 대비를 유지한다.
- 섹션 사이에 작은 잎 구분자 또는 낮은 채도의 색면만 사용한다.
- 캐릭터 프로필, 정원 꾸미기, 모험 설정처럼 존재하지 않는 기능을 암시하지 않는다.

## 6. 가장 작게 적용할 수 있는 1차 MVP

### 범위

1. **팔레트 미세 조정**
   - 다크·라이트 배경과 surface를 조금 더 따뜻한 정원색으로 조정한다.
   - 새 색상은 민트, 세이지, 씨앗 노랑, 하늘색 보조색까지만 허용한다.

2. **Today hero만 성장 모험 카드로 변경**
   - 상단 카드 안에 저대비 언덕색 면, 작은 점선 경로, 기존 `TinySprout`를 배치한다.
   - 연속 기록과 7일 데이터는 기존 값을 그대로 쓴다.
   - 레이아웃 높이와 CTA 동작은 유지한다.

3. **목표 행의 카드화**
   - `TodoItem`을 분리된 둥근 행으로 보이게 한다.
   - 완료 상태에 민트 배경과 작은 잎 포인트를 사용한다.
   - 토글, 삭제, 반복·일회성 구분 로직은 그대로 둔다.

4. **Report 인사이트 카드만 모험 일지화**
   - 기존 인사이트 배열을 점선 경로와 씨앗 마커로 표현한다.
   - 통계 계산, 차트 구조, 섹션 순서는 바꾸지 않는다.

5. **핵심 카피만 조정**
   - Today hero와 Report 제목·빈 상태 정도만 “작은 여정”, “남긴 흔적”, “성장 로그” 톤으로 바꾼다.
   - 4개 언어 키를 동시에 수정하며 “퀘스트”, “보상”, “레벨”은 사용하지 않는다.

### MVP에서 제외

- 새 이미지 에셋과 외부 일러스트 라이브러리
- 캐릭터 시스템 또는 얼굴이 있는 마스코트
- 지도, 장소, 배지, 재화, 경험치, 타이머
- 새로운 애니메이션 시스템
- DB 및 통계 변경
- 내비게이션 변경
- 모든 화면을 한 번에 재설계하는 작업

이 MVP는 `theme`, `HomeScreen`, `TodoItem`, `ReportScreen`, `translations`, `DESIGN.md` 중심으로 제한할 수 있다. 먼저 Today와 Report에서 콘셉트가 Tiny Growth답게 보이는지 확인한 뒤 Goal과 Settings로 확장하는 것이 적절하다.

### MVP 성공 기준

- 참고 앱의 이름이나 로고 없이 봐도 Finch 화면으로 오인되지 않는다.
- 첫 화면에서 “작은 기록이 쌓이는 자연스러운 여정”이 3초 안에 전달된다.
- 목표 추가, 완료, 기록 작성까지 기존 탭 수와 조작 횟수가 늘어나지 않는다.
- 다크·라이트 모드에서 본문과 버튼의 접근성 대비가 유지된다.
- 데이터가 0개인 상태와 많은 상태 모두에서 장식이 정보를 가리지 않는다.
- iOS와 Android의 작은 화면에서 hero와 목표 제목이 잘리지 않는다.

## 7. Tiny Growth라는 이름과의 적합성

**적합도는 높다.** `Tiny`는 매일 부담 없이 남기는 작은 목표와 기록을, `Growth`는 씨앗·새싹·정원이라는 자연 은유와 시간에 따른 축적을 직접 설명한다. 성장 모험 로그는 이 이름에 “작은 변화들이 하루의 여정이 된다”는 서사를 더해준다.

다만 이름과 어울리려면 모험의 규모도 작고 조용해야 한다. 거대한 판타지 여행, 전투, 보상 수집, 캐릭터 육성으로 확장하면 `Tiny Growth`보다 일반적인 게임형 습관 앱처럼 보인다. 반대로 다음 세 문장을 기준으로 유지하면 브랜드와 잘 맞는다.

- 목표는 오늘 심는 작은 씨앗이다.
- 기록은 오늘 지나온 길에 남기는 짧은 메모다.
- 리포트는 작은 흔적이 모여 보이는 월간 성장 일지다.

따라서 권장 콘셉트 정의는 다음과 같다.

> **Tiny Growth는 거대한 모험을 약속하는 앱이 아니라, 매일의 작은 성장 자체를 조용한 모험으로 기록하는 앱이다.**

이 정의는 기존 생산성 도구의 신뢰감, 새싹 중심의 고유 정체성, 사용자가 부담 없이 매일 기록하고 싶은 따뜻한 분위기를 함께 유지한다.
